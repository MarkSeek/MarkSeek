## Project Overview

MarkSeek is an AI-native knowledge workspace built around Markdown. The UI follows a 3-panel layout (left sidebar, center editor, right panel).


## Key Dependencies

- **React 18** + TypeScript — UI framework
- **Vite 6** — build tool (port 9000, host 0.0.0.0)
- **Milkdown 7** — WYSIWYG Markdown editor (Nord theme, CommonMark preset)
- **CSS variables** — unified light theme system
